# Планы реализации

Здесь живут планы волн: `YYYY-MM-DD-<тема>-plan.md`. Формат и обязательная
секция «архитектурная проверка» — в скилле
[`writing-plans`](../../.agents/skills/writing-plans/SKILL.md).

План пишется Team Lead'ом до старта волны и раздаётся исполнителям кусками:
бриф ссылается на конкретные шаги, а не на файл целиком. *Что* строим — GitLab
issues; *как* идёт волна — [`docs/agents/03_orchestration.md`](../agents/03_orchestration.md).
