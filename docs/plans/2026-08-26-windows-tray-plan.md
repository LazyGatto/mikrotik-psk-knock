# План: трей-иконка Windows-клиента mkpk-client — issue #29

Дата: 2026-08-26. Решения maintainer'а: трей нужен; «сворачивание» = закрытие
окна прячет его в трей (не в таскбар); зависимость `fyne.io/systray` одобрена
контекстом запроса (Wails v2 трея не имеет, v3 — альфа).

## Архитектурная проверка

1. **Документы:** CHANGELOG; issue #29. Протокол не затронут.
2. **Инварианты:** knock-поток не меняется — трей зовёт тот же код, что HTTP-хендлер.
3. **Совместимость:** не затронута.
4. **Новые файлы:** `desktopui/state.go` (реестр open-until), `cmd/mkpk-client/tray_windows.go`
   (+stub для остальных ОС), `cmd/mkpk-client/assets/*.ico`. Новых каталогов уровня репо нет.
5. **Зависимость:** `fyne.io/systray` (BSD-3) — только в `cmd/mkpk-client`;
   отказ инициализации трея не валит приложение (guard + лог).
6. **Локализация:** строки трея EN/RU из настроек клиента (языка окна).
7. **Живой прогон:** только maintainer на Windows — у агента нет Windows-GUI.
   Гейт покрывает кросс-сборку (`go:desktop-win`) и unit-тесты реестра/парсера.

## Дизайн

- `desktopui.Server` получает публичный `Knock(...)` (общий для HTTP и трея) и
  реестр статусов: успешный knock со статусом open пишет
  `openUntil = now + allowed_timeout` (парсер go-duration с поддержкой d/w),
  `Status()` отдаёт снимок, `SetOnChange` — колбэк для трея.
- Трей (windows-only, goroutine рядом с `wails.Run`): иконка обычная / с
  зелёной точкой при «хоть один открыт», тултип «mkpk — N открыто», меню:
  «Открыть mkpk» (WindowShow), пункт на сервис (клик = knock, заголовок
  «socks5 · kz — открыто · ещё 42м»), «Выход» (runtime.Quit). Тикер 30s
  обновляет отсчёт и роняет зелёную точку по истечении.
- Окно: `HideWindowOnClose: true` — `X` прячет в трей; кнопка minimize остаётся
  системной (wails v2 её не перехватывает).
- Иконки: multi-entry PNG-ICO (16/24/32/48) из брендового тайла; вариант
  с зелёной точкой. Генератор одноразовый (scratchpad), коммитятся .ico.

Готово, когда: verify = 0 (включая новые unit-тесты), maintainer подтверждает
на Windows: сворачивание по X в трей, зелёная точка после открытия, knock из
меню, отсчёт, выход.
