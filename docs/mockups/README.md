# UI mockups (design reference)

Interactive prototypes from the design pass for the provisioning UI. These are
design-tool exports (Vue-style, mock state) — reference for rebuilding
`client/internal/web/assets`, not shipped code.

- `mkpk-provision v2.dc.html` — **current** design: top-level users, multi-router, dashboard (per addendum #1).
- `mkpk-provision.dc.html` — earlier v1 (reference).
- `Edge states.dc.html` — empty/error/edge-state gallery.
- `support.js` — shared prototype JS/data.
