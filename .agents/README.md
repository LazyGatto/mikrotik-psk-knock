# Каталог агентской обвязки

Проектный материал для агентов. Операционное руководство — роли, лестница
делегирования, оркестрация волн, уроки — живёт в
[`docs/agents/`](../docs/agents/README_FOR_AGENTS.md); здесь лежат скиллы,
на которые эти документы ссылаются.

```text
.agents/
├── skills/
│   ├── devils-advocate/   # обязательная роль критического ревью, DA-гейт
│   ├── writing-plans/     # дизайн → распределяемый план реализации
│   └── verification/      # никакого «готово» без кода возврата
└── README.md
```

Это **процессные** скиллы, общие для всего репозитория. Техническое
macOS/Swift-знание (SwiftPM, AppKit↔SwiftUI, подпись, нотаризация, iCloud
Keychain) лежит отдельно, рядом с кодом, которого касается:
[`client-macos/.agents/skills/`](../client-macos/.agents/skills/).

Заводите проектный скилл только для знания, действительно специфичного для
mkpk — протокол токена, семантика RouterOS, инварианты провижининга. Не
дублируйте здесь общеорганизационные скиллы без осознанного локального
переопределения.
